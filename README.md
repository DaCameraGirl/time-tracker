# Time Tracker

Clock in. Clock out. Get paid for every minute.

A simple desktop app to track your freelance work sessions. One click to start, one click to stop — every session saved automatically.

## Features
- One-click Clock In / Clock Out
- Live running timer (hours, minutes, seconds)
- Auto-saves every session to `time_log.csv`
- "View Time Log" opens your full session history
- Stays on top of all other windows

## Run it
```
python timetracker.pyw
```

Requires Python 3.x. No extra installs needed.
